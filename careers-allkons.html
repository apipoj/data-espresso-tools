สร้าง Chat Platform ให้ Allkons ซึ่งเป็นลูกค้าหลักของ All-in-AI — ระบบสื่อสารภายในองค์กรที่ผสาน AI เข้ากับการทำงานจริง ผู้ใช้สามารถ chat กับเพื่อนร่วมงาน หรือสั่งงาน AI agent ได้ในหน้าจอเดียวกัน

📱

Frontend Developer

Flutter • Mobile App

สิ่งที่จะทำ

  • พัฒนา Mobile App (iOS & Android) ด้วย Flutter
  • สร้าง UI/UX สำหรับระบบ Chat ที่ใช้งานง่ายและสวยงาม
  • พัฒนาระบบ real-time messaging (WebSocket)
  • Integrate กับ AI chat features
  • ทำ Push Notifications และ offline support

คุณสมบัติ

  • มีประสบการณ์ Flutter อย่างน้อย 1 ปี
  • เข้าใจ state management (Bloc / Riverpod / Provider)
  • เคยทำระบบ chat หรือ real-time app
  • คุ้นเคยกับ REST API & WebSocket
  • มี portfolio หรือ app ที่เคยทำ

Nice to Have

  • เคยใช้ Firebase (FCM, Firestore)
  • มีประสบการณ์ UI animation / Lottie
  • เข้าใจ CI/CD สำหรับ mobile app
⚙️

Backend Developer

Node.js • Cassandra

สิ่งที่จะทำ

  • ออกแบบและพัฒนา Backend API สำหรับ Chat Platform
  • สร้างระบบ real-time messaging ที่ scale ได้
  • ออกแบบ database schema บน Apache Cassandra
  • Integrate AI/LLM สำหรับ intelligent chat features
  • จัดการ authentication, authorization, security

คุณสมบัติ

  • มีประสบการณ์ Node.js (Express / NestJS) อย่างน้อย 1 ปี
  • มีประสบการณ์ NoSQL database (Cassandra / MongoDB / DynamoDB)
  • เข้าใจ WebSocket / Socket.io / real-time systems
  • คุ้นเคยกับ message queue (Redis, RabbitMQ, Kafka)
  • เข้าใจ RESTful API design & security best practices

Nice to Have

  • มีประสบการณ์กับ Apache Cassandra โดยตรง
  • เคยทำระบบ chat / messaging platform
  • เข้าใจ Docker, Kubernetes, cloud deployment
  • มีความรู้ด้าน AI/ML หรือ LLM integration
