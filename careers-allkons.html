Enterprise Communication Platform

🏢 สร้าง Platform ให้ลูกค้าองค์กรขนาดใหญ่

พัฒนา Enterprise Communication Platform ให้ลูกค้าองค์กรของ All-in-AI — ระบบที่ต้องรองรับการใช้งานระดับ enterprise ทั้งด้าน performance, security และ scalability

โปรเจคนี้ต้องการทีมที่พร้อมสร้างระบบตั้งแต่ต้น — ทั้ง Mobile App (Flutter) และ Backend ที่รองรับ real-time communication ในระดับ enterprise

📱

Frontend Developer

Flutter • Mobile App

สิ่งที่จะทำ

  • พัฒนา Mobile App (iOS & Android) ด้วย Flutter
  • สร้าง UI/UX ที่ใช้งานง่ายและสวยงามระดับ enterprise
  • พัฒนาระบบ real-time communication (WebSocket)
  • ทำ Push Notifications และ offline support
  • ทำงานร่วมกับทีม Backend อย่างใกล้ชิด

คุณสมบัติ

  • มีประสบการณ์ Flutter อย่างน้อย 1 ปี
  • เข้าใจ state management (Bloc / Riverpod / Provider)
  • เคยทำ real-time app หรือ app ที่มี complexity สูง
  • คุ้นเคยกับ REST API & WebSocket
  • มี portfolio หรือ app ที่เคยทำ

Nice to Have

  • เคยใช้ Firebase (FCM, Firestore)
  • มีประสบการณ์ UI animation / Lottie
  • เข้าใจ CI/CD สำหรับ mobile app
⚙️

Backend Developer

Node.js • Cassandra

สิ่งที่จะทำ

  • ออกแบบและพัฒนา Backend API ระดับ enterprise
  • สร้างระบบ real-time communication ที่ scale ได้
  • ออกแบบ database schema บน Apache Cassandra
  • จัดการ authentication, authorization, security
  • ทำงานร่วมกับทีม Frontend อย่างใกล้ชิด

คุณสมบัติ

  • มีประสบการณ์ Node.js (Express / NestJS) อย่างน้อย 1 ปี
  • มีประสบการณ์ NoSQL database (Cassandra / MongoDB / DynamoDB)
  • เข้าใจ WebSocket / Socket.io / real-time systems
  • คุ้นเคยกับ message queue (Redis, RabbitMQ, Kafka)
  • เข้าใจ RESTful API design & security best practices

Nice to Have

  • มีประสบการณ์กับ Apache Cassandra โดยตรง
  • เคยทำระบบ real-time / messaging platform
  • เข้าใจ Docker, Kubernetes, cloud deployment
  • มีความรู้ด้าน cloud deployment (AWS/GCP)
